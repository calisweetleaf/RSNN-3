4. **`rsl_memory_system.py`: four shape/dtype crashes on the `store_memory` / `update_consciousness_state` path** (the path `runtime/rosemary_full.py` runs every step and on REST). Each hit in sequence on the canon default config; each fixed at the line that raised:

   - `store_memory`: BVT-2 evidence was the `[1, eigen_dim]` projection -> `.flatten()[:belief_dimension]`, the same shaping `update_consciousness_state` already used.
   - `RecursiveBayesianUpdatingSystem._compute_likelihood`: `sigmoid(similarity.squeeze())` was 0-d (IndexError) -> `.reshape(-1)` so the existing 0.5 padding applies. Operator note: this makes the likelihood one cosine score + 0.5 for every other hypothesis; whether per-hypothesis likelihood was intended is a theory call.
   - `EnhancedBayesianVolitionEngine._compute_ethical_projection`: `M @ M.T` (5x5) on `beliefs[:ethical_dim]` -> `M.T @ M` (ethical_dim x ethical_dim); `_assess_convergence` compares `beliefs[:ethical_dim]` with the manifold mean (same slice).
